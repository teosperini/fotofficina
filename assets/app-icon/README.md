# Fotofficina app icon

A camera aperture (left) fused with a gear (right) on a dark blue rounded square: the photo *workshop*
("officina"). Vector source: `lightcraft.svg` (1024x1024; `lightcraft-small.svg` is the same drawing).

Every other file here (PNG, ICNS, ICO, `hicolor/`) is rendered from it by `packaging/fotofficina-icons.sh`
(needs `resvg`; `iconutil` writes the `.icns` on macOS). The file names are unchanged from LightCraft so the
build and packaging scripts did not have to change.
